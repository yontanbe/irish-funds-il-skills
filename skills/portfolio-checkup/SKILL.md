# בדיקת תיק קיים

## הכלל הראשון
אתה מנתח נתונים שהמשתמש נתן ומציג מה שעולה מהם. אתה לא אומר לו מה למכור או לקנות. בסוף כל תשובה כותבים את הנוסח שבקובץ `DISCLAIMER.md`.

## מה מבקשים מהמשתמש
רק שני דברים: מספר נייר וסכום בשקלים לכל אחזקה. לא מבקשים שם, מספר חשבון, סיסמה או צילום מסך של חשבון הבנק. אם המשתמש שולח יותר ממה שצריך, משתמשים רק במספרי הנייר ובסכומים.

## הרצה
```
python3 -m engine.cli checkup --holdings '{"1159250": 60000, "1159243": 40000}'
```

המנוע מחזיר:
1. משקל כל אחזקה באחוזים.
2. עלות שנתית משוקללת.
3. חשיפה משוערת לארה"ב.
4. כמה מהתיק בקרנות סינתטיות.
5. אזהרות.

## האזהרות ומה הן אומרות
1. נייר שלא בדאטה. לא נכלל בחישוב. אומרים למשתמש אילו ניירות נשארו בחוץ, ולא מנחשים מה הם.
2. יותר מ-80 אחוז בארה"ב. ריכוזיות במדינה אחת.
3. יותר מ-30 אחוז בנאסדק 100. חפיפה גבוהה עם S&P 500 ותנודתיות גבוהה.
4. יותר מ-10 אחוז בקרנות ענף או מדינה. אלה תוספות ולא בסיס.
5. שתי קרנות על אותו מדד. אין בזה פיזור נוסף.

אזהרה היא מידע, לא הוראה. מסבירים מה היא אומרת, והמשתמש מחליט.

## איזון מול יעד
אם למשתמש יש הרכב יעד מהסקיל `portfolio-builder`, משתמשים בפונקציה `rebalance`:

```python
from engine import load_data, build_portfolio, rebalance
data = load_data()
target = build_portfolio("shlosha-ezorim", 100, 0, data["portfolios"])
rebalance({"1159250": 70000, "1159094": 20000, "1159169": 10000}, target["lines"], deposit=5000)
```

התוצאה מראה לכל קרן כמה יש, כמה צריך להיות, ומה ההפרש. מסבירים שעדיף לסגור פערים דרך הפקדות חדשות, כי מכירה ברווח היא אירוע מס. לשאלות מס אישיות מפנים לרואה חשבון או יועץ מס.

## דמי ניהול לאורך זמן
כדי להמחיש כמה שווה הפרש בעלות:
```
python3 -m engine.cli fees --monthly 2000 --years 20 --return 7 --fee 0.8
```
הנחת התשואה היא של המשתמש. אומרים במפורש שזו הדגמה חשבונית ולא תחזית.

## מה לא עושים
1. לא נותנים ציון לתיק.
2. לא אומרים שהתיק טוב או רע.
3. לא ממציאים נתונים על נייר שלא בדאטה.
4. לא שומרים את נתוני האחזקות מעבר לשיחה.
