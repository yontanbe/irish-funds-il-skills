# מבני תיק

## הכלל הראשון
אלה מבנים לדוגמה ללימוד והשוואה. אף אחד מהם אינו המלצה. בסוף כל תשובה כותבים את הנוסח שבקובץ `DISCLAIMER.md`.

המבנים מוגדרים בקובץ `data/portfolios.json`. כמה מהתיק יהיה מנייתי קובע השאלון בסקיל `portfolio-builder`.

## כלל ההשוואה
בכל פעם שמציגים קרן, מציגים לידה את החלופות על אותו סוג מדד ואת הפרש העלות השנתית. כך המשתמש רואה תמיד את iShares מול Invesco. המנוע עושה את זה לבד בפקודת `build`, ואפשר גם ישירות:

```python
from engine import load_data, alternatives
alternatives("1209220", load_data()["funds"])
```

## תיק 1: עולמי אחד
קרן אחת שמחזיקה אלפי חברות, מכל המדינות ומכל הענפים. אין מה לאזן.

שלוש אפשרויות, ותמיד מציגים את שלושתן עם המחיר:
1. Invesco FTSE All-World, מספר נייר 1209220. מפותחים ומתפתחים. פיזית.
2. iShares MSCI ACWI, מספר נייר 1159235. מפותחים ומתפתחים. פיזית.
3. Invesco MSCI World, מספר נייר 1185164. מפותחים בלבד. סינתטית.

```
python3 -m engine.cli build --template olami-ehad --answers answers.json
```

## תיק 2: מניות עולם ואגח
שתי קרנות. אחת של כל המניות בעולם, כמו בתיק 1, ואחת של אגח. היחס נקבע לפי רמת הסיכון מהשאלון.

שתי אפשרויות לרכיב האגח:
1. אגח עולמי כללי: iShares Core Global Aggregate Bond, מספר נייר 1159102. אגח ממשלתי וקונצרני מכל העולם. הקרן מגודרת לדולר ולא לשקל, ואומרים את זה למשתמש.
2. אגח כללי ישראלי: משבצת ריקה. זו לא קרן אירית. המשתמש מחפש קרן מחקה על מדד אגח כללי ישראלי ובוחר לבד.

```
python3 -m engine.cli build --template olami-ve-agach --answers answers.json --bond global_agg
```

## תיק 3: טריאתלון
שלוש רגליים שוות בחלק המנייתי, שליש לכל אחת.

### רגל 1: טכנולוגיה
1. `sp_tech_ishares`: iShares S&P 500 Information Technology, מספר נייר 1159193.
2. `us_tech_invesco`: Invesco US Technology Select Sector, מספר נייר 1185180.
3. `nasdaq_ishares`: iShares NASDAQ 100, מספר נייר 1159243.
4. `nasdaq_invesco`: Invesco NASDAQ-100 Swap, מספר נייר 1186063.

### רגל 2: S&P 500
1. `regular_ishares`: iShares Core S&P 500, מספר נייר 1159250.
2. `regular_invesco`: Invesco S&P 500, מספר נייר 1183441.
3. `equal`: Invesco S&P 500 Equal Weight, מספר נייר 1207208. כל חברה מקבלת משקל דומה.
4. `combined`: חצי רגיל וחצי משקל שווה.
5. `value`: קרן ערך. משבצת ריקה, כי במחקר לא נמצאה קרן ערך אירית בתל אביב. יש קרנות ישראליות, למשל תכלית TTF S&P 900 Pure Value מנוטרלת מטח, מספר 5133681. המשתמש בוחר לבד.
6. `hedged`: S&P 500 מנוטרל מטבע. משבצת ריקה, כי במחקר לא נמצאה קרן אירית מנוטרלת לשקל.

### רגל 3: עולמי
1. `all_invesco`: Invesco FTSE All-World, מספר נייר 1209220.
2. `all_ishares`: iShares MSCI ACWI, מספר נייר 1159235.
3. `ex_us`: עולם בלי ארהב. 60 אחוז אירופה (1159094) ו-40 אחוז מתפתחים (1159169). זה קירוב, וחסרות בו יפן, קנדה ואוסטרליה.

```
python3 -m engine.cli build --template triathlon --answers answers.json --tech sp_tech_ishares --sp equal --global ex_us
```

### מה חייבים להגיד על טריאתלון
שלוש הרגליים חופפות. מדד הטכנולוגיה, S&P 500 והמדד העולמי מחזיקים את אותן ענקיות אמריקאיות. התיק מרוכז בארהב ובטכנולוגיה יותר ממה שנראה. המנוע מחשב חשיפה משוערת לארהב, ומציגים אותה תמיד. הגרסה של עולם בלי ארהב מקטינה את החפיפה.

## איך להציג מבנה
מציגים את השורות, החלופות והפרשי העלות, העלות המשוקללת, החשיפה לארהב וההערות. לא משנים משקלים ביד.

## ביצועי עבר
מי שרוצה לראות איך הקרנות שבתיק התנהגו בעבר עובר לסקיל `funds-performance`. לא מצטטים תשואות מהזיכרון.

## איזון
פעם בשנה, או כשרגל סוטה ביותר מ-5 נקודות אחוז מהיעד. עדיף לאזן דרך ההפקדות החדשות ולא דרך מכירה, כי מכירה ברווח היא אירוע מס. הפונקציה `rebalance` במנוע מחשבת כמה חסר בכל רגל.
